Shelby 1U PQC Gateway Series

The Shelby 1U PQC Gateway Series is a high-performance cybersecurity gateway engineered to enable seamless adoption of Post-Quantum Cryptography (PQC) for existing enterprise and industrial infrastructures. Powered by Intel® Core™ processors supporting 14th, 13th, and 12th Gen platforms, it delivers high-performance cryptographic processing while preserving existing server architectures through a non-intrusive gateway deployment model. With enterprise-grade hybrid TLS, TPM 2.0, high-availability architecture, and flexible PCIe expansion, the Shelby 1U Series provides a future-ready security platform for defense, finance, telecommunications, healthcare, and critical infrastructure.

Why Shelby 1U PQC Gateway Series?
  • Protect Existing Infrastructure — Secure legacy servers without replacing current IT investments.
  • Accelerate PQC Migration — Adopt PQC-enabled hybrid TLS without disrupting existing infrastructure.
  • Mission-Critical Reliability — Combines redundant power and hardware bypass NICs to maximize service continuity.
  • High-Speed Fiber Connectivity — Supports 10GbE SFP+ SR fiber networking for high-bandwidth security deployments.
  • Enterprise-Class Trusted Hardware — Onboard TPM 2.0, Secure Boot, and full-disk LUKS encryption.
  • High-Density 1U Deployment — Standard 19" 1U rackmount form factor optimizes rack space utilization.

Features, Advantages and Benefits

Features
1
Ready Computing Platform

Powered by Intel® Core™ processors supporting 14th, 13th, and 12th Gen platforms (up to 24 cores), providing robust cryptographic processing performance required for demanding Post-Quantum Cryptography (PQC) workloads.

2
Enterprise-Class Power Redundancy

Supports a 300W 1+1 hot-swappable redundant power supply (100–240V AC), allowing continuous system operation in the event of a single PSU failure.

3
Enterprise-Class Trusted Security

Provides hardware-backed security through onboard TPM 2.0, Secure Boot, and LUKS disk encryption, with TPM-based private key protection for enhanced system integrity and cryptographic key security.

4
High Availability & Fail-Safe Networking

Supports High Availability (HA) deployment and hardware bypass networking for enhanced service and network resilience, with Syslog-compatible logging for enterprise management and SIEM integration.

Advantages
1
Enterprise-Class Network Expansion

Supports PCIe Gen4 x16 expansion for 10GbE and 25GbE network interfaces, including hardware bypass configurations, enabling flexible high-bandwidth connectivity and enhanced network resilience for enterprise and critical infrastructure environments. (*Note: Customer infrastructure is required to support SNMP/IP management for bypass network routing.)

2
High-Density 1U Deployment

Optimized for standard 19-inch rack environments, delivering high-density cybersecurity deployment and simplified cable management in a compact 1U footprint to maximize server rack space utilization.

Benefits
1
High Availability Architecture

Combines dual-Gateway High Availability (HA), 1+1 redundant power, and hardware bypass networking to enhance service availability, power resilience, and network path continuity for mission-critical deployments.

2
Seamless PQC Integration

Enables existing servers and network infrastructure to adopt Post-Quantum Cryptography (PQC) protection through the Shelby 1U PQC Gateway Series without replacing existing hardware or redesigning system architecture.

3
Validated Low Latency & High Concurrency

Delivers only ~2.3% additional PQC handshake latency while supporting 20,000 concurrent connections and over 1.55 million ML-KEM handshakes in endurance testing.
